# Project Documentation

This directory contains architecture navigation and the repository-wide application audit.

## Architecture Map

[CARTODEX_MAP.md](CARTODEX_MAP.md) is the generated navigation map for the current repository. Use
it to locate module ownership, entry points, dependencies, data flows, conventions, and common
change paths.

## Application Audit

[audit/README.md](audit/README.md) is the working index for the repository-wide audit. The audit
documents current behavior before proposing replacements, records evidence separately from
decisions, and tracks open questions that require further investigation.

They describe the current application and review findings;
they are not implementation plans unless an OpenSpec change explicitly adopts them.
